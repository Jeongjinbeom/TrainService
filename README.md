# 열차 예매 프로젝트

해당 프로젝트는 관리자가 열차 일정을 등록하고 사용자가 예매할 수 있는 환경을 제공하는 프로그램입니다.
사용자와 관리자에 따른 다양한 기능을 지원하며, 데이터베이스 연동을 통해 로그인, 회원가입, 열차 등록, 열차표 취소, 열차 관리 등을 구현하였습니다.

##  📋 기능

### 사용자
- **로그인 및 회원가입**: 사용자가 로그인 및 회원가입을 할 수 있습니다.
- **회원 수정**: 사용자 정보(비밀번호, 핸드폰 번호 등)를 수정할 수 있습니다.
- **열차 예매&조회**: 사용자 열차를 조회하고 예매할 수 있습니다.
- **열차 취소**: 사용자가 출발하지 않은 열차를 취소할 수 있습니다.

### 관리자
- **열차 등록**: 열차 일정을 등록할 수 있습니다.
- **열차 조회&삭제**: 등록한 열차를 조회하고 일정을 삭제할 수 있습니다.

## 🗃️ 데이터베이스

### Users 테이블
- `Username`: 사용자 이름
- `User_id`: 사용자 ID (로그인 ID)
- `password`: 사용자 비밀번호
- `phone`: 사용자 핸드폰번호
- `is_admin`: 관리자, 사용자 역할 (사용자(1), 관리자(0))

### Trains 테이블
- `train_id`: 열차 ID
- `train_name`: 열차 이름
- `depature_station`: 열차 출발 역
- `arrival_station`: 열차 도착 역
- `depature_time`: 열차 출발 시간
- `max_seat`: 최대 좌석
- `type_adult`: 어른 티켓 가격
- `type_kid`: 어린이 티켓 가격

### Reservations 테이블
- `res_id`: 예약 ID
- `res_adult`: 어른 티켓 수
- `res_child`: 어린이 티켓 수
- `res_total`: 티켓 총 금액
- `res_time`: 예약 일자
- `res_status`: 예약 상태(취소, 확정)

## 🚀 프로젝트 실행 방법

1. **환경 설정**
   - Java Development Kit (JDK) 17 이상 설치
   - JDBC (Java Database Connectivity) 설치 및 설정

2. **데이터베이스 설정**
   - `user`, `Reservations`, `Trains`테이블을 생성합니다.
   - 데이터베이스 연결 설정을 `dao` 파일에 구성합니다.

3. **프로젝트 빌드 및 실행**
   - 프로젝트를 클론한 후, IDE에서 프로젝트를 열고 빌드합니다.
   - `Main.java` 파일을 실행하여 애플리케이션을 시작합니다.

4. **관리자 로그인**
   - 데이터 베이스에 관리자 값을 넣은 후에 진행합니다(is_admin).

5. **사용자 로그인**
   - 기본적으로 사용자 ID와 비밀번호를 사용하여 로그인합니다.

## 🛠️ 기술 스택

- **Java**: 애플리케이션의 주요 프로그래밍 언어
- **JDBC (Java Database Connectivity)**: Java와 Oracle 간의 연결을 위한 라이브러리
- **Git**: 소스 코드 버전 관리 시스템
